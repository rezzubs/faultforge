# Publications

Papers whose techniques were developed and evaluated with FaultForge. The
techniques are implemented in `faultforge.encoding`, and the experiments use
the [Encoded Memory](../experiments/encoded_memory/README.md) reference
experiment.

To cite FaultForge itself, see [`CITATION.cff`](../CITATION.cff).

[IEEE Xplore](https://ieeexplore.ieee.org/document/11539549)
